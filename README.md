# Video Game Sales Dashboard - Power BI

Este projeto foi desenvolvido com o objetivo de **testar e praticar meus conhecimentos em Power BI e análise de dados**, utilizando o dataset **Video Game Sales**.

A ideia foi criar um dashboard voltado para a análise de **vendas de jogos**, explorando informações como vendas por plataforma, gênero, região e outros indicadores presentes no dataset.

Este foi o meu **primeiro dashboard desenvolvido utilizando Power BI**, portanto, ainda é um projeto inicial e possui bastante espaço para melhorias. Mesmo assim, ele representa o ponto de partida da minha jornada de aprendizado e prática na área de **Dados e Business Intelligence**.

## Tecnologias

* Power BI
* CSV
* Dataset: Video Game Sales

## Objetivo

Praticar conceitos de:

* Análise de dados
* Indicadores de vendas
* Visualização de dados
* Criação de dashboards no Power BI

> Projeto desenvolvido para fins de estudo e prática.
